## Files

| File | What it does |
|---|---|
| `KDD_data.py` | Fetches the dataset, builds the data matrix `D` (one-hot encoding, dropping constant columns, min-max scaling) and the label vector `y`. Saves `D.npy` and `y.npy`. |
| `filename` | Q1 solution (k-means with random projection) |
| `CSE558_Q2_solution.ipynb` | Q2 solution (sketched least squares) |
| `.gitignore` | Excludes the large `.npy` data files |

`D.npy` is about 229 MB, which is over GitHub's 100 MB file limit, so it is **not**
included in this repo. It is generated by `KDD_data.py`.

## How to run

1. Install the requirements:
   ```
   pip install numpy pandas matplotlib scikit-learn jupyter
   ```
2. Generate the data (this downloads the dataset the first time, so it needs
   internet access):
   ```
   python KDD_data.py
   ```
   This creates `D.npy` (shape 494021 x 116) and `y.npy` in the current folder.
3. Open the notebooks from the same folder and run them top to bottom
   (Kernel -> Restart & Run All). Both notebooks load `D.npy` and `y.npy` from
   their own folder.
